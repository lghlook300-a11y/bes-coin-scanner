# BES CONFIRM 재확인 검색기 V2.8

업로드한 `BES V4.9.1 Champion`의 4시간봉 상승 구조를 웹 검색기에 옮긴 버전입니다. 자동매수 기능은 없으며, 빗썸 실시간 수급과 결합해 차트를 다시 볼 후보만 표시합니다.

## 4시간봉 구조

- Pivot 좌우 12봉, 구조 저점 탐색 360봉, CONFIRM 후 72봉 재무장 규칙을 사용합니다.
- 현재 빗썸 요청에서는 최근 200개 4시간봉으로 재생하므로 상태 전이 규칙은 같지만, 360봉 전체가 필요한 오래된 구조는 잡지 못할 수 있습니다.
- `PRE-A`: 구조적 피벗 저점 A가 확정되고 첫 B를 기다리는 상태
- `B 진행`: A 이후 첫 피벗 고점 B가 생기고 C를 기다리는 상태
- `C 눌림 대기`: B 이후 A보다 높은 피벗 저점 C가 생긴 상태
- `ABC 확인`: 확정 4시간봉 종가가 B를 돌파해 파란 CONFIRM이 발생한 상태
- 확정 4시간봉 종가가 A 아래로 내려가면 구조를 초기화합니다.

## 진입 생명주기

1. `CONFIRM 재확인 대기`: 파란 CONFIRM 직후 바로 추격하지 않습니다.
2. `첫 시도`: 현재가가 CONFIRM 대비 -2~+5%, 2차 수급과 매수체결 우위가 있고 전용 손절 거리가 5% 이내일 때 표시합니다.
3. `단기 실패`: C 방어 가격과 CONFIRM -3% 중 높은 값을 기준으로 만든 전용 손절선을 이탈한 상태입니다. 원래 A 구조 전체가 끝났다는 뜻은 아닙니다.
4. `재진입`: 단기 실패 뒤 새로운 1차·2차 수급이 발생하고 CONFIRM 가격을 다시 회복한 경우 한 번 더 표시합니다.
5. `단기 성공`: 시도 가격에서 +5%에 도달한 상태입니다.
6. `추격 금지`: CONFIRM 대비 +15%를 넘은 종목입니다. 이후 +5% 이내로 충분히 눌리면 다시 대기 상태로 돌아갑니다.
7. `구조 종료`: 현재가가 확정 A 아래로 내려간 상태입니다.

`지금 소액 검토`에는 첫 시도와 재진입만 최대 3종목 표시합니다. 나머지는 `A·CONFIRM 추적`에서 단계와 이유를 확인합니다. 기존 수급 TOP 5와 오전 9시(KST) 기준 24시간 카운팅은 유지합니다.

## 실행

```bash
pip install -r requirements.txt
python realtime_scanner.py
```

브라우저에서 `http://localhost:8080`을 엽니다. 실시간 운영에는 프로그램이 종료되지 않는 24시간 서버가 필요합니다.
