# BES 반복 수급·가격 방어 검색기 V2

빗썸 Public WebSocket의 `ticker`, `trade`, `orderbook`을 계속 수신해 정상 KRW 종목의 자금 유입을 탐지합니다. 주문·금액·손절·가상계좌 기능은 없습니다.

15분 검색기를 함께 실행하지 않습니다. 20~90초 안의 반복 수급과 최초 포착가 방어를 검증합니다.

## 출력 상태

- `수급 유입`: 평소보다 체결대금과 매수 체결이 증가
- `수급 1회`: 통합점수 60점 이상인 초기 자금 유입
- `수급 2회 확인`: 20~90초 내 수급이 반복되고 최초 포착가 대비 -1.5% 이내 방어
- `초입 검토`: 2회 확인 후 가격 방어가 유지된 신호, 3분간 화면 고정
- `고위험 초입`: 같은 조건이지만 BTC가 단기 하락 중
- `탈락`: -3%·기준 저점 붕괴 또는 강한 매도 전환
- `과열·추격 금지`: 이미 단시간 급등
- `수급 이탈`: 매도 체결과 가격 하락이 동시에 확대

점수는 1차 포착 조건과 우선순위에만 사용합니다. 핵심 통과 조건은 반복 수급과 가격 방어이며, 화면에는 두 차례 수급 강도·최초 포착가·무효화 가격·MAE를 표시합니다.

## 실행

```bash
pip install -r requirements.txt
python realtime_scanner.py
```

브라우저에서 `http://localhost:8080`을 엽니다. 실시간 운영에는 프로그램이 종료되지 않는 24시간 서버가 필요합니다.
