# BES 수급·A 복합 검색기 V2.4

빗썸 Public WebSocket의 `ticker`, `trade`, `orderbook`을 계속 수신해 정상 KRW 종목의 자금 유입을 탐지합니다. 기존 수급 검색기(Champion)는 보존하고, 수급 포착 종목의 4시간봉 A 구조를 추가 확인하는 `A+수급` 방식(Challenger)을 한 화면에서 병행 검증합니다. 주문·금액·손절·가상계좌 기능은 없습니다.

- `기존 수급`: 기존 V2.2 판정
- `A+수급`: 최근 확인된 4H 스윙 저점에서 7% 이내이고 기준 저점을 방어한 종목
- A 자체는 매수 신호가 아니며 수급 2회·가격 방어가 함께 있어야 시도 가능
- 성과 기록에 방식, A 가격, A와의 거리 값을 별도 저장

## 일일 재포착 기록

- 같은 신호가 유지되는 동안은 1회로 계산합니다.
- 신호가 사라진 뒤 30분 이상 지나 다시 포착될 때만 횟수가 증가합니다.
- 전체 포착, A 부근, 수급 2회, 시도 가능 횟수와 포착가격 흐름을 따로 기록합니다.
- KST 날짜별로 저장하며 최근 90일 기록을 보존합니다.
- 재포착 횟수는 검증 자료일 뿐 기존 행동 판정에는 영향을 주지 않습니다.

15분 검색기를 함께 실행하지 않습니다. 20~90초 안의 반복 수급과 최초 포착가 방어를 검증합니다.

## 화면 행동 판정

- `소액 시도 가능`: 2차 수급, 최초 포착가 방어, 현재 매수 수급 유지, 손절 거리 3.2% 이내
- `돌파 확인`: 위 조건과 함께 직전 10초 이전 단기 고점을 매수 우위로 돌파
- `기다림`: 1차 수급만 포착했거나 현재 가격 방어·수급 확인이 부족
- `매수 금지`: 무효화 가격 이탈, 매도 우세 또는 포착 후 단기 +6% 이상 급등

탐지 로직은 V2.1을 보존하고 행동 판정만 매초 새로 계산합니다. 따라서 3분 표시 중에도 수급이 약해지면 즉시 `기다림` 또는 `매수 금지`로 바뀝니다. BTC 약세는 절대 차단하지 않고 비중 축소 경고로 표시합니다. 화면에는 진입 가능 구간, 단기 돌파 기준, 무효화·손절 가격을 함께 표시합니다.

탈락 종목은 30분간 다시 포착하지 않습니다. BTC 단기 하락 중에는 2차 수급이 1차 이상일 때만 통과합니다. `/api/performance`에서 각 신호의 30분·1시간·3시간 수익률, 최고수익률, MAE, +5%·+10% 도달시각, 행동 판정이 바뀐 시각·가격과 탈락 사유를 확인할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
python realtime_scanner.py
```

브라우저에서 `http://localhost:8080`을 엽니다. 실시간 운영에는 프로그램이 종료되지 않는 24시간 서버가 필요합니다.
