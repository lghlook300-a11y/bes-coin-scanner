# BES 단일 실시간 초입 검색기

빗썸 Public WebSocket의 `ticker`, `trade`, `orderbook`을 계속 수신해 정상 KRW 종목의 자금 유입을 탐지합니다. 주문·금액·손절·가상계좌 기능은 없습니다.

15분 검색기를 함께 실행하지 않습니다. 실시간 조건을 충족한 종목만 표시하며 일시적 흔들림은 30초간 `조건 약화`로 구분합니다.

## 출력 상태

- `수급 유입`: 평소보다 체결대금과 매수 체결이 증가
- `수급 포착`: 통합점수 60점 이상인 초기 자금 유입
- `초입 검토`: 통합점수 75점 이상이며 매수체결 우위가 강화
- `고위험 초입`: 같은 조건이지만 BTC가 단기 하락 중
- `조건 약화`: 포착 후 조건이 흔들리는 30초 유예 상태
- `과열·추격 금지`: 이미 단시간 급등
- `수급 이탈`: 매도 체결과 가격 하락이 동시에 확대

화면 점수와 통과 점수는 동일합니다. 일반 조건 이탈은 30초 연속 지속되면 제거하고, 강한 매도 이탈·과열·넓은 호가는 즉시 제거합니다. 화면에는 최초 포착가·-3% 기준가·최근 3분 저점도 함께 표시됩니다.

## 실행

```bash
pip install -r requirements.txt
python realtime_scanner.py
```

브라우저에서 `http://localhost:8080`을 엽니다. 실시간 운영에는 프로그램이 종료되지 않는 24시간 서버가 필요합니다.
